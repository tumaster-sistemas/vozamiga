# Voz Amiga

Asistente de voz en la web para adultos mayores y personas con discapacidad
de Villa El Salvador. Sin instalar apps, sin crear cuenta: escaneas, hablas
y te responde en voz alta.

## Problema
Los adultos mayores y personas con discapacidad quedan fuera de los servicios
digitales: interfaces pequeñas, formularios y apps que no saben usar. En Villa
El Salvador la información de ayuda (emergencias, comedores, trámites) está
dispersa y mal accesible.

## Solución
Interfaz de voz simple: el usuario habla, Voz Amiga entiende y responde
en voz alta y en pantalla. Incluye guía de emergencia con teléfonos reales
y lectura de textos en voz alta.

## ODS
ODS 10 — Inclusión digital de adultos mayores y personas con discapacidad.

## Stack
- HTML / CSS / JavaScript (sin framework, corre en cualquier celular)
- Web Speech API del navegador (voz)
- Gemini API - gemini-2.5-flash (plan gratuito)
- GitHub Pages (publicación)

## Cómo usar
1. Abre https://tumaster-sistemas.github.io/vozamiga/
2. Ingresa tu API key de Gemini (se guarda solo en tu dispositivo)
3. Pulsa el botón Hablar

## Cómo correr en local
Clona el repositorio y abre index.html en Chrome.
